# Estimate balanced nested distance-based variance components

Estimate balanced nested distance-based variance components

## Usage

``` r
estimate_nested_variance_components(design, truncate = FALSE, tol = 1e-10)
```

## Arguments

- design:

  Canonical nested Design Object.

- truncate:

  Also return a separate zero-truncated sensitivity estimate.

- tol:

  Numerical tolerance.

## Value

A nested variance-component specification.
