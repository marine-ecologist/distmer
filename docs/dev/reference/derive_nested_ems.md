# Derive EMS for a balanced nested random-intercept hierarchy

Derive EMS for a balanced nested random-intercept hierarchy

## Usage

``` r
derive_nested_ems(design, tol = 1e-10)
```

## Arguments

- design:

  Canonical Design Object with a \`/\`-generated hierarchy.

- tol:

  Numerical tolerance.

## Value

A named list of exact nested EMS specifications.
